# Лаванда

Личный ИИ-чат на Gemini: не тормозит на длинных чатах, есть папки, поиск Google с источниками, фото и файлы, голосовой ввод и синхронизация между ПК и телефоном. Всё бесплатно.

## Как установить (около 10 минут)

**1. Разместить приложение на GitHub Pages**

1. Зарегистрируйся на [github.com](https://github.com/signup).
2. Справа вверху нажми **+** → **New repository**. Имя: `lavanda`, оставь **Public**, нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file** и перетащи все файлы из этой папки. Внизу нажми **Commit changes**.
4. Открой **Settings** → **Pages**. В разделе Branch выбери `main` и `/ (root)`, нажми **Save**.
5. Через 1–2 минуты приложение откроется по адресу `https://ТВОЙ-ЛОГИН.github.io/lavanda/`.

Репозиторий публичный, но в нём только код приложения. Твои чаты, ключ и токен туда не попадают.

**2. Установить как приложение**

- **ПК (Chrome или Edge):** открой адрес и нажми значок установки в адресной строке. Или: Настройки Лаванды → «Установить на это устройство».
- **Android (Chrome):** меню ⋮ → «Установить приложение» или «Добавить на главный экран».
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

**3. Подключить Gemini (бесплатно)**

Открой [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → **Create API key** → вставь ключ в Лаванду. Сделай это на каждом устройстве.

**4. Включить синхронизацию**

Настройки → Синхронизация → ссылка «создание токена». Галочка **gist** уже стоит, срок выбери **No expiration**, нажми **Generate token**. Вставь токен на ПК и на телефоне — один и тот же.

## Полезно знать

- Синхронизируется текст чатов и папки. Фото и файлы остаются на устройстве, где их прикрепили.
- Голосовой ввод работает в Chrome, Edge, на Android и в Safari. В Firefox кнопки микрофона нет.
- Бесплатный лимит Gemini ограничен. Если он кончился, подожди минуту или выбери модель Flash-Lite.
- На бесплатном ключе Google может использовать переписку для улучшения своих моделей. Пароли, документы и личные данные лучше не отправлять.
- Из России AI Studio и Gemini API работают только через VPN.
- Чтобы обновить приложение, загрузи новые файлы в тот же репозиторий поверх старых.
